LepusLab · Edge Vision Platform
Vela
Vision that runs where it happens.

Vela is LepusLab's edge vision platform — a native C++/CUDA runtime for real-time, multi-model computer vision that runs entirely on the device. Capture, stitch, inference, and decision all happen on the edge. No cloud, no upload, no per-frame bill.

Jetson OrinC++ / CUDATensorRTZero-copy NVMMMulti-model
01

The whole pipeline, at the edge

Most vision AI ships pixels to the cloud and waits. Vela keeps the entire pipeline — dual-camera capture, panorama stitching, multi-model inference, and the decision it drives — on the device itself. It is designed to use Jetson's vision IP and ML accelerators fully, without a server in the loop.

02

What the platform gives you

I.

One pipeline, three runtimes

The same tuned vision pipeline runs unchanged on PyTorch in the lab, on CoreML/ANE on an iPhone, and on CUDA/TensorRT on the device. Write the logic once; deploy it to whatever silicon the use case needs.

II.

A zero-copy native engine

The production engine is C++/CUDA end to end. Frames stay in GPU memory (NVMM / DMABUF) from sensor to encoder — no copies, no GIL, no Python in the hot path. That headroom is what lets one Orin stitch 4K and run several models at once.

III.

Many models, one budget

YOLO-family models run in a mixed FP16 and INT8 pipeline, with tiled inference and lightweight post-processing staged under a fixed frame budget. The scheduler is tuned to extract as much useful ML throughput as Jetson can provide.

IV.

Local-first by design

Everything works with no internet. The device serves its own stream and control over BLE and Wi-Fi Direct, so a remote field with no signal is just another deployment — and there is no cloud invoice per hour of footage.

03

The pipeline, stage by stage

From two lenses to a local stream, every stage runs on the device. Only a small downscaled frame ever leaves GPU memory — the model reads it to decide, and the full-resolution path stays zero-copy.

01 · Capture

Dual 4K

Two MIPI sensors, hardware-synced via NVIDIA Argus.

02 · Warp

Undistort + stitch

CUDA dewarp and panorama stitch — one wide frame, without CPU round trips.

03 · Inference

Mixed pipeline

YOLO FP16 and INT8 models, tiled inference, and lightweight post-processing share one frame budget.

04 · Compose

ROI stream

Analysis output shapes the real-time region-of-interest stream on the device.

05 · Encode

NVENC H.264

Hardware-encoded on-device, patent-clean codec path.

06 · Serve

Local stream

RTSP + HLS over Wi-Fi Direct, straight to the phone in your hand.

Built and running in C++/CUDA. Detection and stream composition moved into the native engine to reduce copy and GIL overhead, allowing tiled inference and post-processing to stay inside a 30 fps frame budget.

04

Portable across the edge

The vision logic is the source of truth. It gets a detection backend and a video path per runtime — the tracking, scheduling, and event math stay identical everywhere.

Lab bench

PyTorch · MPS

Tune and validate the pipeline live, measure recall and latency. The reference the other two derive from.

On-device

CoreML · ANE

The same logic is validated on mobile neural hardware, keeping the phone-side and edge-device analysis paths aligned.

Production

CUDA · TensorRT

4K input, stitching, multi-model inference, and NVENC output run on Jetson Orin.

Vela starts in sports because the environment is demanding: wide fields of view, long recording windows, low latency, and unreliable networks. The focus is not a single match feature, but a stable edge vision pipeline that can be operated on site.
