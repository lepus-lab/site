Vela
현장에서 보고, 현장에서 끝냅니다.

Vela는 LepusLab의 엣지 비전 플랫폼입니다. 여러 ML 모델을 기기 위에서 실시간으로 돌리는 네이티브 C++/CUDA 런타임이죠. 촬영부터 스티칭, 추론, 그리고 그에 따른 판단까지 — 전부 기기 안에서 끝냅니다. 클라우드도, 업로드도, 프레임당 요금도 없습니다.

Jetson OrinC++ / CUDATensorRTZero-copy NVMMMulti-model
01

파이프라인 전체를, 엣지에서

대부분의 비전 AI는 픽셀을 클라우드로 올려 보내고 기다립니다. Vela는 다릅니다 — 듀얼 카메라 촬영, 파노라마 스티칭, 멀티모델 추론, 그리고 거기서 나오는 판단까지, 파이프라인 전체를 기기 안에 그대로 둡니다. 서버 없이 Jetson 플랫폼의 Vision IP와 ML 가속기를 최대한 활용하도록 설계했습니다.

02

플랫폼이 건네는 것

I.

하나의 파이프라인, 세 런타임

똑같이 튜닝한 비전 파이프라인이 손대지 않은 채로 세 곳에서 돕니다 — 랩의 PyTorch, 아이폰의 CoreML/ANE, 그리고 기기의 CUDA/TensorRT. 로직은 한 번만 짜고, 유즈케이스가 요구하는 실리콘 어디에든 얹습니다.

II.

복사 없는 네이티브 엔진

프로덕션 엔진은 처음부터 끝까지 C++/CUDA입니다. 프레임은 센서에서 인코더까지 GPU 메모리(NVMM·DMABUF)에 그대로 머뭅니다 — 복사도, GIL도, 핫패스의 파이썬도 없죠. 이렇게 확보한 여유가, Orin 하나로 4K를 스티칭하면서 여러 모델을 동시에 돌리게 해줍니다.

III.

여러 모델을, 한 프레임 예산에

YOLO 계열 모델을 FP16·INT8로 조합하고, 타일 추론과 후처리를 믹스 파이프라인으로 엮습니다. Jetson의 ML 가속 성능을 프레임 예산 안에서 끝까지 끌어내도록 스케줄링합니다.

IV.

처음부터, 로컬 퍼스트

인터넷 없이도 전부 동작합니다. 기기가 스스로 스트림과 제어를 BLE·Wi-Fi Direct로 내보내니, 신호 하나 없는 오지 경기장도 그저 또 하나의 설치 현장일 뿐이죠. 영상 한 시간마다 날아오는 클라우드 청구서도 없습니다.

03

파이프라인, 한 단계씩

두 개의 렌즈에서 로컬 스트림까지, 모든 단계가 기기 위에서 돕니다. GPU 메모리를 벗어나는 건 작게 줄인 프레임 한 장뿐 — 모델이 그걸 읽어 판단하고, 원본 해상도 경로는 끝까지 복사 없이 흐릅니다.

01 · 촬영

듀얼 4K

두 개의 MIPI 센서, NVIDIA Argus로 하드웨어 동기화.

02 · 보정

왜곡 보정 + 스티칭

CUDA로 왜곡을 펴고 파노라마로 합칩니다. 넓은 한 화면을, CPU 복사 없이.

03 · 추론

믹스 파이프라인

YOLO FP16·INT8 모델, 타일 추론, 경량 후처리를 한 프레임 예산 안에 배치합니다.

04 · 구성

ROI 스트림

분석 결과를 바탕으로 필요한 영역을 실시간 스트림으로 구성합니다.

05 · 인코딩

NVENC H.264

기기에서 하드웨어 인코딩, 특허 리스크 없는 코덱 경로.

06 · 송출

로컬 스트림

Wi-Fi Direct로 RTSP+HLS, 손 안의 폰까지 곧바로.

이미 C++/CUDA로 구현해 돌아가고 있습니다. 디텍터와 스트림 구성 로직을 네이티브 엔진으로 옮겨 복사·GIL 글루를 줄였고, 타일 추론과 후처리가 30fps 프레임 예산 안에서 함께 돕니다.

04

엣지 어디에서든

비전 로직이 원본이자 기준입니다. 런타임마다 탐지 백엔드와 영상 경로만 갈아 끼울 뿐, 추적·스케줄링·이벤트 연산은 어디서나 똑같습니다.

랩 벤치

PyTorch · MPS

파이프라인을 실시간으로 튜닝·검증하고 재현율과 지연을 잽니다. 나머지 둘이 여기서 갈라져 나왔습니다.

온디바이스

CoreML · ANE

같은 로직을 모바일 뉴럴 엔진 위에서 검증합니다. 현장 기기와 폰 사이의 분석 경로를 함께 맞춥니다.

프로덕션

CUDA · TensorRT

Jetson Orin에서 4K 입력, 스티칭, 멀티모델 추론, NVENC 출력까지 이어집니다.

05

초기 적용 영역: 스포츠 현장

Vela는 넓은 시야, 긴 녹화 시간, 낮은 지연, 현장 네트워크 제약이 동시에 걸리는 스포츠 환경을 첫 적용 영역으로 삼았습니다. 특정 경기 기능보다 엣지 비전 파이프라인의 안정성과 운영성을 먼저 검증합니다.

응용 · 스포츠

현장형 엣지 비전 장비

듀얼 4K 입력을 하나의 넓은 화면으로 합치고, 필요한 분석과 스트리밍을 기기 안에서 처리합니다. 서버 설치나 클라우드 업로드 없이 운영하는 구조입니다.

넓은 시야 캡처

듀얼 4K 입력을 로컬에서 보정·스티칭해 넓은 화면을 안정적으로 확보합니다.

온디바이스 분석

YOLO FP16·INT8 모델과 TensorRT 경로를 조합해 Jetson의 ML 가속 성능을 활용합니다.

로컬 운영

BLE와 Wi-Fi Direct 기반 제어·스트리밍으로 현장 네트워크 부담을 낮춥니다.

장비화 가능한 구조

클럽, 시설, 촬영 업체, 렌탈 업체가 반복 설치·회수하기 쉬운 엣지 장비를 지향합니다.

동호회 클럽유소년 아카데미풋살장·구장 대여 업체스포츠 촬영 전문 업체장비 렌탈 업체코치·분석가
