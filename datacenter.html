Architecture

리퀴드쿨링으로 전환하기 어려운 레거시 데이터센터에서, OCP 철학과 19인치 레거시 랙을 결합한 에어쿨링 최적화 전략. 커스텀 전원 아키텍처와 ODM 협력을 통해 PUE 30~45% 절감을 목표로 합니다.

1.30 Target PUE
30–45% Cooling Energy Reduction
1.3yr ROI Period (10 racks)
₩130M Annual Savings / 10 racks
01 / Problem Statement

레거시 DC의
구조적 비효율

01

에어플로우 혼합

핫아일/콜드아일 컨테인먼트 미적용으로 냉기와 열기가 혼합되어 냉각 효율이 급락합니다. OEM 서버의 IO/전원 혼재 배치가 케이블 관통을 만들어 기류를 방해합니다.

PUE 1.65 – 1.80 (레거시 평균)
02

전원 아키텍처 비효율

40대 서버 랙에 PSU 80개가 각각 AC→DC 변환 손실을 발생시킵니다. HA 리던던시로 인해 각 PSU가 30~40% 저부하로 운영되어 효율이 최적 구간을 벗어납니다.

PSU 수 80개 → 중앙화 후 7–8개
03

테크니션 작업 환경

OEM 서버의 IO 포트가 리어(핫아일 쪽)에 배치되어, 핫아일 온도 최대 52°C 환경에서 작업이 불가피합니다. OSHA 기준 작업 가능 시간이 25%로 제한됩니다.

핫아일 최대 52°C vs OSHA 권고 30°C
왜 리퀴드쿨링으로 전환이 어려운가
시설 구조 바닥 배관·방수 처리 없는 기존 시설에서 리퀴드쿨링 도입은 대규모 공사가 필요
임차 시설 건물주 동의 없이 배관 공사 불가 — 임차 DC의 현실적 제약
투자 여력 리퀴드쿨링 전환 CAPEX가 막대하여 중소규모 DC 오퍼레이터에게 진입 장벽
장비 호환성 기존 서버에 콜드플레이트 미장착 — 장비 교체 없이 전환 불가능
02 / Architecture Approach

2-Track
Bridge Architecture

OCP/Meta가 추구하는 프론트 IO / 리어 전원 철학을 19인치 레거시 환경에 맞게 재해석합니다. 리퀴드쿨링 없이, 기존 19인치 랙 자산을 그대로 활용하면서 에어쿨링 효율을 극대화하는 브릿지 아키텍처입니다.

Track A — Long Term

커스텀 샤시

OCP Inspired 19인치 호환 커스텀 샤시. 프론트 IO + 리어 전원 탭-오프 구조로 테크니션이 콜드아일에서 모든 작업을 완결합니다.

프론트 IO + 리어 전원 배치로 핫아일 작업 제거
PSU 내장 없음 → 버스바 탭-오프 커넥터로 수전
19인치 폼팩터 유지 — 기존 랙 자산 활용
대만 ODM(MiTAC, AIC, Wiwynn)과 공동 개발
개발 리드타임: 12~24개월 / NRE 1회성
Track B — Fast Entry

레거시 랙 버스바 키트

기존 19인치 랙을 개조하는 레트로핏 키트. Track A 샤시 개발 전에 시장 검증과 초기 수익을 확보하며 업셀링 경로를 만듭니다.

2U Power Shelf + 0U 수직 DC 버스바 구성
기존 AC PDU와 병존 → 점진적 전환 가능
12V 시작으로 인증 리스크 최소화
Legrand ORV3 레퍼런스 설계 기반
Track A 도입 고객으로 업셀링 GTM

04 / AC → DC Transition Methodology

전압 전략
12V → 48V

서버에 내장된 개별 AC-DC PSU를 제거하고 랙 레벨 DC 버스바로 전환하는 과정에서, 12V로 시작하여 48V를 2세대 목표로 단계적으로 이행합니다. 물리 원칙상 48V는 동일 전력에서 전류를 1/4로 줄여 버스바 도전 손실을 1/16까지 감소시키지만, 레거시 호환성과 인증 리스크를 고려한 현실적 순서가 중요합니다.

항목 12V (Phase 1) 48V (Phase 2) 선택 근거
동일 전력 시 전류 기준 1/4 (유리) 물리 원칙 (P=IV)
버스바 도전 손실 (P=I²R) 기준 1/16 (유리) 고전류 경로 손실 감소
레거시 장비 호환성 높음 낮음 기존 서버 병존 필요
안전 인증 복잡도 낮음 (KC/UL 단순) 높음 (고전압 안전) 12V 선행 진입 근거
서버 내부 VRM 불필요 추가 VRM 필요 샤시 설계 복잡도
OCP 생태계 표준 성숙 Open Rack V3 추진 중 장기 방향성 확인
19인치 버스바 레트로핏 구성
